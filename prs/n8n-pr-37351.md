## TL;DR

Added two small String helpers `isBlank()`/`isNotBlank()` to workflow expressions — `isBlank` returns true for empty or whitespace-only strings, mirroring `isEmpty` but with `trim()`.

## Why (instead of fixing an issue)

User asked for a small new function that will merge quickly rather than fixing a bug. `isEmpty` checks `=== ""` only, so `"   ".isEmpty()` is false (surprising). Workflows often treat whitespace-only as empty (Baserow filters, Cal.com inputs). New helpers avoid `"value.trim() === \"\""` boilerplate and follow existing validation pattern.

## Logic

```ts
function isBlank(value: string): boolean { return value.trim() === ''; }
function isNotBlank(value: string): boolean { return !isBlank(value); }
```
Docs: `section: validation`, `docURL: ...#string-isBlank`, examples: `"   ".isBlank() → true`, `"  hello  ".isBlank() → false`.
